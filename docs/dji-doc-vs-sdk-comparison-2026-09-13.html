十一、差异与问题清单

问题 1：DroneModeCode 包含 mode_code=20 (POI_ORBIT) 未见于 DJI 文档

严重程度类型影响范围
低@Inferred 推断值DroneModeCode 枚举

详情：SDK DroneModeCode 定义了 POI_ORBIT(20)，但 DJI 文档的 mode_code 枚举仅列到 19（M4 系列）或 17（RC Pro）。 POI 环绕是 v1.14 新增功能，mode_code=20 可能是 DJI 未在文档中明确列出的值。 状态：已标注 @Inferred，需真机验证。

问题 2：PhotoFormat 枚举未与字段绑定

严重程度类型影响范围
中设计不一致CameraStatePushData.CameraState.photoFormat

详情：PhotoFormat 枚举已定义（包含 RJPEG=7, DLT664=16），但 CameraStatePushData.CameraState.photoFormat 字段使用 Integer 而非枚举类型， 且 PhotoFormat 缺少 @JsonValue/@JsonCreator 注解。枚举仅作为常量参考，实际序列化时不使用类型安全绑定。 建议：待真机验证后，将字段类型改为 PhotoFormat 枚举并添加 Jackson 注解。

问题 3：POI 事件方法命名可能重复

严重程度类型影响范围
中潜在重复定义EventMethod.POI_STATUS_NOTIFY / POI_CIRCLE_STATUS

详情：DJI 文档定义事件 poi_status_notify（字段：status, reason, circle_radius, circle_speed, max_circle_speed）。 SDK 同时定义了 POI_STATUS_NOTIFY ("poi_status_notify") 和 POI_CIRCLE_STATUS ("poi_circle_status") 两个事件方法。 PoiCircleStatusData POJO 字段匹配文档 poi_status_notify 数据结构，但关联的事件方法不确定。 建议：核实 poi_circle_status 是否为 DJI 文档中独立的协议方法，还是应合并到 poi_status_notify。

问题 4：CameraState.cameraMode 与 CameraMode 枚举值域不一致

严重程度类型影响范围
低设计已知差异CameraStatePushData.CameraState.cameraMode

详情：CameraStatePushData.CameraState.cameraMode 使用 int 而非 CameraMode 枚举，因为 CameraState 的 cameraMode 枚举值含义（0=拍照,1=录像,2=拍照+录像）与 CameraMode（0=拍照,1=录像,2=智能低光,3=全景拍照）不同。 这是已知的设计差异，不是 Bug，但需在文档中说明。
