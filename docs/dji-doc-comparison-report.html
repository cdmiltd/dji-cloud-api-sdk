4. 发现的差异与不一致

差异 1：ServiceProgressData status 枚举值不完整 中

项目详情
文件command/event/system/ServiceProgressData.java
DJI 文档output.status 定义 8 种枚举值：
canceled（取消或终止）、failed（失败）、in_progress（执行中）、ok（执行成功）、paused（暂停）、rejected（拒绝）、sent（已下发）、timeout（超时）
SDK 代码Javadoc 仅标注 3 种：in_progress、ok、failed
影响分析代码使用 String 类型，运行时可正确接收全部 8 种值。但 Javadoc 不完整会误导开发者对状态值的判断
建议更新 Javadoc 补全 8 种 status 枚举值；考虑创建 ServiceStatus 枚举类型以提供类型安全

差异 2：remaining_power_for_return_home 适用范围描述 低

项目详情
文件protocol/method/PropertySetMethod.java L84
DJI 文档v1.16.1 发布记录标注该属性适用于 "Dock3 & Dock2"
SDK 代码Javadoc 标注为 "M3D/M4D 飞行器属性"
影响分析这是视角差异：属性是飞行器属性（aircraft property），但通过 Dock2/Dock3 的 property/set 通道设置。SDK 描述从设备维度出发可能不够精确
建议更新 Javadoc 注明"通过 Dock2/Dock3 property/set 通道设置"，而非仅标注"M3D/M4D 飞行器属性"

差异 3：DjiErrorCode 514xxx 系列不完整 中

项目详情
文件protocol/error/DjiErrorCode.java
DJI 文档514xxx 机场操作错误码仅有范围描述（514101-514185），无逐个清单；514300-514304 有逐个描述
SDK 代码标注 @Inferred：514xxx 仅有范围描述无逐个清单；514300-514304 来源为 deepwiki 非官方文档；4xxxx/6xxxx Pilot 错误码未收录
影响分析514xxx 范围内的错误码无法通过 describe() 方法获取精确描述，仅能返回范围级提示
建议待 DJI 官方文档补充 514xxx 逐个清单后补录；持续关注 DJI 错误码文档更新
